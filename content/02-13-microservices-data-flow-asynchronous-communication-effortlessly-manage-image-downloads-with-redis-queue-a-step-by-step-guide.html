View files in the directory: root@ec6c6307531d:/app# ls image_downloader.py main.py requirements.txt You can see that currently there are only image_downloader.py, main.py, and requirements.txt. First, image_downloader.py is used to download images and save them to files. The code is as follows: import requests def download_image(url): response = requests.get(url) with open(url.split("/")[-1], "wb") as f: f.write(response.content) print(f"Image downloaded and saved") Next, main.py creates the Redis queue, imports the function, and enqueues the task. The code is as follows: from redis import Redis from rq import Queue from image_downloader import download_image q = Queue(connection=Redis()) q.enqueue( download_image, " ) requirements.txt defines the libraries that the Python code depends on: rq==2.6.0 requests==2.32.5 redis==6.4.0 Next, run the script: root@ec6c6307531d:/app# python main.py root@ec6c6307531d:/app# You won't see anything in this terminal, but we can check the data in Redis: root@ec6c6307531d:/app# redis-cli KEYS '*' 1) "rq:job:27148712-d3c5-4762-bc8d- 8af71001320f" 2) "rq:queue:default" 3) "rq:queues" root@ec6c6307531d:/app# We now have tasks in our message queue!
